## 功能说明与边界

- 豆瓣页：热播电视剧、热播电影、最新电影、最新电视剧、最新动漫、TOP250。
- Netflix页：热播电视剧、热门电影、最新电影、最新电视剧、最新动漫、高分佳作。元数据、Netflix标签、热度与评分来自豆瓣，明确标注，非Netflix官方榜单；没有虚构其官方TOP250。最新类按首播/首映排序，含待播。
- 每个频道/分类的完整已加载列表、页码、滚动位置保留到进程结束；主动刷新只替换当前列表。磁盘推荐缓存和本次会话列表是不同职责。
- 延迟是实际媒体请求到媒体前缀验证的耗时，排除排队，不是ICMP Ping。小于1秒绿，1至3秒橙，3秒及以上红；NA只代表没有影片，连接/媒体失败为ERR。
- 速度优先尽快起播、偏低带宽HLS；高清优先最多等待6秒比较首批候选的清单分辨率或明确画质标签。未知清晰度不凭来源品牌猜测，也不承诺永远找到全网最高画质。清单声明和当前解码器实测分别标注。
- 媒体分辨率/编码/帧率来自当前播放器；码率优先使用媒体声明，未声明时可显示明确标注的播放数据采样值。暂停保留最后值，新来源清零。HLS通常没有单一文件的精确大小，估算值明确标注。下载吞吐量不当作码率。
- 多季进度使用片名中的明确季数和已保存的集名，不臆造没有元数据的季数。
- 从资源/搜索页看过的无豆瓣ID记录，有明确同名、同年、同类型元数据时也可显示在豆瓣海报上续播。首次成功播放后保存豆瓣身份，原来源记录不被删除；年份等信息缺失的旧记录仍可从历史页打开，不做有歧义的自动关联。
- 弹幕已有XML/JSON数据直链、本地文件及源自带数据解析；未增加弹幕网站影片自动匹配。网站主页/影片网页不等同于弹幕数据接口。
- 来源可用性随片名与网络变化，32个配置不等于32条都能播放。云盘、AI、直播、RTX/4K/HDR及全源长时间稳定性不属于本轮验收。
