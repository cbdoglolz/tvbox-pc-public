## 风险和保护

- 原作品key为douban@id，新TMDB身份必须带类型和命名空间；不覆盖旧收藏/历史，分季关联需保留语义。低置信匹配不自动绑定。
- 搜索与discover不同：关键词跨页补齐，筛选/排序只在已查询范围时明确Partial；不把首屏过滤说成全库结果。
- 豆瓣推荐接口有提供方数量上限，国别/类型/评分字段可能缺失。显示可查询范围、缺失和缓存状态。
- TMDB/IMDb/豆瓣分值独立；未知分不是0分，TMDB整剧评分不假称某一季评分。
- TMDB凭据不进入源码、发布包、日志或普通prefs；401/429/断网不阻塞原点播，不重复弹窗。
- 现版本项目Version是0.3.0，但AssemblyVersion/FileVersion仍为0.2.0.0；在0.4交付时同步修正，不篡改已发布0.3包。
