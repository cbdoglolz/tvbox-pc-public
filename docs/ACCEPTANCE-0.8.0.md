# TVBox PC 0.8.0 验收记录

日期：2026-11-07。Windows 11 x64。0.7.0原验收已归档并逐字节核对；历史记录未覆盖。

| 项目 | 实际结果 |
| --- | --- |
| 自动检查 | 218项行为断言，另1行汇总；比0.7.0新增29项。测试使用独立临时目录；严格Release x64零警告零错误。 |
| 今日发现 | 原生窗口显示五个数字、顶部进度条；手动选第1部后内容/选中数字改变。自动轮播已观察到不同序号。冷数据库重开当天顺序与十天避重、候选不足降级通过夹具验证；没有实际等待十一天。 |
| 首页/海报 | 顶部分类统一名称；重复分组消失。原生窗口评分在海报外下方，未遮挡图片，白色圆圈信息图标删除。新选中背景已实机观察到更强紫色反差。正常页底部不再固定放“加载更多”，失败时可重试；该最后一项为代码/构建核对。 |
| 推荐瀑布流 | 原生详情相似推荐19部→39部，鼠标在推荐区内滚轮触发第二页；单一外层滚动条，继续推荐按钮可滚到。 |
| 弹幕 | 设置启用的独立QA配置中，电影实际自动查找/加载9600条B站正片弹幕，原生画面已显示随片播放；未粘贴弹幕链接。真实接口另做一次搜索→正片cid→XML→9600条解析验证。 |
| 播放/统计 | QA影片真实出画面并播放超过1分钟，1920×838/H.264/HLS；非凡资源记录1次速度胜出、1次连接、约6.52秒至首帧。首帧分辨率晚到的回读补记通过行为断言，尚未用含该补丁的新原生进程复验。 |
| 片源缓存 | 回归场景证明第二次只实际调用曾成功的站点；显式刷新重新调用三个站点。按配置/片名/年份/类型/集数隔离，七天过期，真实播放失败降级。非32站全部真实播放验收。 |
| 缓存清理 | 夹具实际创建旧文件与活动文件，旧文件被删除、活动文件与统计/每日发现保留；默认1024 MiB、每五分钟检查。未实际填满1 GiB做长时间后台测试。 |
| 数据/静音 | 播放前默认输出静音并回读确认；原生启动前实际TVBOX_PC_DATA_DIR回读为.tools下独立QA目录。未使用终止进程清理测试。 |

未覆盖：实际优酷弹幕、自建聚合部署、全部剧集切换/长时间稳定性、完整DPI矩阵、HDR/RTX、异机Runtime、广告自动抹除。源码实现与夹具通过不等于上述场景已经实机完成。

32个默认来源和所有订阅地址/来源key未变更；栏目名称与UI分组调整逐项见[0.8.0更新报告](reports/TVBox-PC-v0.8.0-Update-Report.md)。
