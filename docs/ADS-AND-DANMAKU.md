# 弹幕接入与广告处理说明

核查日期：2026-11-07，适用于 TVBox PC 0.8.0。

## 自动弹幕如何使用

设置 → 弹幕 → 启用弹幕。开启时同时开启“自动搜索与加载”，无需每部影片再粘贴弹幕地址。当前正在播放的影片也会发起查询；切集自动重新匹配，切源或切集会取消旧请求，旧结果不能覆盖新集。

优先使用站点自带弹幕；没有或返回空内容时，按片名、作品类型、可核对的年份和集数搜索B站正版影视/番剧目录。不会使用普通投稿搜索的解说、预告或剪辑。遇到多个同名版本、无法确定的电影正片或缺失集数，会保留手动导入并显示原因，不会任意加载第一条。

留空服务地址即可使用B站匹配；有多平台需求时，填写兼容弹弹play的服务根地址、`/api/v2/` 地址或带令牌的路径。现已支持 `search/episodes` → `comment/{episodeId}`，以及B站XML、Dandan `comments` 的 `p/m` 格式和原有DPlayer等格式。自动搜索不影响视频解析、换源和播放；单次查询有超时、16 MiB载荷与10万条渲染输入上限。成功结果缓存24小时，受后台缓存上限管理。播放页仍可关闭显示、选择自带源或手动导入。

启用后，片名和集数会发往B站或用户选填的聚合服务。默认关闭；不会上传影视文件、凭据或观看历史文件。无痕模式不保存新增弹幕缓存与片源统计。

## 实际核查与接入边界

| 平台/项目 | 本版结果 | 边界 |
| --- | --- | --- |
| B站正片目录 | 实际搜索《武林外传》2011电影版、获取正片cid并解析9600条XML弹幕 | 不保证每部影视都有对应弹幕；接口风控、地区与版本差异可能失败，XML池不等于全部历史弹幕 |
| 弹弹play官方服务 | 核查了官方接入文档 | 官方要求申请应用AppId/AppSecret，本版没有冒用其他应用凭据，也没有宣称内置官方授权 |
| LogVar/danmu_api等自建聚合 | 实现兼容搜索与评论协议，并以独立HTTP夹具验证完整自动链路 | 项目声明支持优酷等多站；本版没有部署服务，实际平台覆盖由用户配置的服务决定 |
| 公共聚合地址 | 测试中遇到DNS失败、403与超时 | 没有把这些地址硬编码为默认服务；未完成优酷真实节目弹幕验收 |

参考：[B站接口维护项目的剧集接口资料](https://github.com/bilibili-plugins/bilibili-api-collect/blob/master/docs/bangumi/info.md)、[XML弹幕资料](https://github.com/bilibili-plugins/bilibili-api-collect/blob/master/docs/danmaku/danmaku_xml.md)、[弹弹play官方接入要求](https://doc.dandanplay.com/open/)、[LogVar作者的协议与部署说明](https://github.com/huangxd-/danmu_api)。优酷开放平台的[视频资料接口文档](https://cloud.youku.com/docs?id=46)不能证明存在无需认证的通用弹幕接口，因此本版没有伪装成直接优酷原生接入。

## 视频中的赌场广告能否去掉

要先辨别广告在哪一层：

| 广告形态 | 可行方法 | 本版处理 |
| --- | --- | --- |
| 站点网页弹窗/脚本广告 | 播放直链，避免运行站点播放器页面；必要时按确定的请求域名拦截 | 沿用现有直链与媒体检测，不增加网页广告脚本 |
| HLS清单内有可靠广告标记或独立广告段 | 对特定站点验证标记、分片与音画时间线后再过滤 | 本版未启用通用自动删段，防止误删正片或破坏续播时间 |
| 已烧录在视频画面里的文字/角标 | 更换干净来源；手动遮罩会盖住对应画面；OCR定位和修复需额外计算且可能误伤字幕 | 本版未实现自动抹字、遮罩或AI修复 |
| 插入正片时间线的广告视频 | 确认时间段后跳过；需要逐版本匹配，否则可能跳过剧情 | 本版未承诺自动识别，不把其他版本的跳过时间直接套用 |

开源项目 [N_m3u8DL-RE 的HLS解析实现](https://github.com/nilaoda/N_m3u8DL-RE/blob/main/src/N_m3u8DL-RE.Parser/Extractor/HLSExtractor.cs)提供按清单规则处理分片的参考，但 `EXT-X-DISCONTINUITY` 也用于正常音画切换，不能把它一律当广告。DNS或Adblock不能删除已经编码进视频的像素。

当前实用选择是更换来源。后续可以先做可撤销的遮罩和用户确认的广告跳过区间；自动删段应按来源逐项实测后启用，不适合直接全局开启。

## 0.8.1补充（2026-11-07）

自动搜索现已检索中文名、原名和可靠别名，明确区分第二季、数字后缀2与第一季。播放器控制层显示持续状态：等待片源、正在搜索、已加载、超时、服务不可用或未覆盖，点击状态可打开弹幕菜单。

本轮实测用户指定的《赛博朋克：边缘行者》第二季第一集：视频实际出画面，但B站正片目录在别名检索后仍未匹配到弹幕库。程序已显示未覆盖原因，不把第一季或剪辑视频的弹幕套给第二季。本轮未获得可用多平台服务地址，不能把这部弹幕描述为已经加载成功。


## 0.8.2补充（2026-11-07；更新上述0.8.1覆盖结论）

本轮自行继续查找服务，找到uosc_danmaku作者维护的弹弹play公共代理。自动搜索现采用它实际支持的 `search/anime?keyword=…` → `bangumi/{animeId}` → `comment/{episodeId}?withRelated=true`；其 `search/episodes` 返回404，不能沿用旧客户端的唯一搜索接口。

指定动画已实际查询到作品19445和第二季第一集弹幕库194450001，下载并解析4,334条。此结论仅表示本轮此作品此集命中，不代表全部番剧或平台均覆盖。0.8.1的失败记录保留作为历史事实，0.8.2已补齐可用服务及正确协议。

启用弹幕/自动搜索后默认依次尝试：站点自带弹幕→公共代理→B站正片。用户填了自定义服务时，自动聚合查询使用该服务；支持旧search/episodes协议，以及404/405/501后改走同一服务的作品/选集协议。搜索严格核对作品名、季数、已知年份、类型和集数，不把第一季或普通投稿视频套用。

新增开关稳定键 `danmaku_builtin_relay`，默认开启；它不会主动开启原本关闭的弹幕功能。成功弹幕缓存24小时，可靠空结果15分钟；临时服务故障不作为空覆盖缓存。公共代理请求至少间隔400ms，故障暂缓一分钟；弹幕菜单“重新搜索弹幕”可绕过缓存重试。切集/切源取消旧请求，手动服务、站点弹幕和文件导入继续保留。公共服务可能限流或失效，播放器应显示状态而不中断视频。

### 本轮服务比较

| 服务与主来源 | 实际结果 | 本版处理 |
| --- | --- | --- |
| [弹弹play官方](https://doc.dandanplay.com/open/) | 官方文档要求应用AppId/AppSecret；当前无本项目官方授权 | 不嵌入他人密钥；未伪称官方直连 |
| [uosc_danmaku公共代理](https://github.com/Tony15246/uosc_danmaku) | 无终端用户Key即可查询；指定第二季第一集4,334条实际解析成功 | 内置为自动聚合来源，可关闭；诚实User-Agent、缓存和限速 |
| [弹幕盒子](https://danmubox.github.io/) | 静态搜索/合并/转换工具，关于页说明数据来自弹幕保存计划、不存储资源 | 可用于人工查找存档；没有当作通用实时API接入 |
| [Animeko](https://github.com/open-ani/animeko) | 有自己的云端弹幕和聚合；本机服务探测要求认证（401） | 未绕过认证，未接入 |
| [公益弹幕库](https://dmku.hls.one/) | 使用视频URL协议而非通用标题搜索；本机访问超时 | 未硬接为Dandan API |
| [LogVar/danmu_api](https://github.com/huangxd-/danmu_api) | 可自建的多平台聚合；本轮若干公开实例DNS/403/401/超时 | 保留自定义兼容接口，未承诺逐一实测优酷等平台 |

以上为2026-11-07本机结果，公共服务可用性可能变化。弹幕时间轴取决于视频版本；片头、剪辑或广告差异可能不同步。本版没有新增发送弹幕、账户登录、公共服务部署或付费订阅。
