# TVBox PC 开发汇总报告

**报告日期：2026年11月6日**  
**覆盖版本：0.1.0 → 0.2.0 → 0.3.0**  
**当前交付：Windows 11 x64 免安装便携版**

本报告根据已保存的代码变更、版本发布和验收记录整理，首次集中汇总此前开发。文中的实播、来源可用数量和接口结果均属于相应版本验收时的记录，本次整理报告没有重新测试所有影片和来源。

## 一、目前已经做到什么

已经交付可直接浏览推荐、搜索影片、自动尝试来源、选集播放、收藏和断点续播的 Windows 点播客户端。首页采用独立的豆瓣/Netflix标签片库页面，原资源站目录保留在“资源”页。

| 功能 | 当前结果 |
| --- | --- |
| 开箱即用 | 自带默认来源，无需先输入视频链接、订阅地址、NAS地址或AI Key。 |
| 推荐选片 | 豆瓣海报、真实评分、热播/最新分类及TOP250。无评分时显示“暂无评分”。 |
| Netflix页面 | 独立分类和列表，使用豆瓣Netflix标签片库、热度及评分，页面明确标注数据来源。 |
| 自动选源 | 配置32个HTTP/API来源；最多三源并行搜索，逐个检测媒体，后台补充候选。 |
| 播放与换源 | 自动起播、失败尝试同片同集的备用源，支持手动切换、暂停、拖动、选集、字幕、全屏和键鼠操作。 |
| 选源偏好 | 支持速度优先、高清优先，设置保存后在下次自动选源生效。 |
| 观看记录 | 收藏、历史和进度本地保存；海报续播显示可确认的季数、集数及时间。 |
| 媒体信息 | 显示实际解码分辨率、编码、码率与封装，可打开详情；采样码率和估算大小明确标注。 |
| 瀑布流 | 滚轮接近底部自动加载；本次程序运行期间，各频道/分类的列表和位置跨页保留。 |
| 更新交付 | 便携包、对应源码和校验文件已发布到同一私有GitHub下载仓库。 |

## 二、各版本完成内容

### 0.1.0：先把基础点播链路做通

日期：2026-11-05。

- 基于现有 Windows 工程继续开发，使用 C#、WinUI 3、Flyleaf/FFmpeg。
- 内置360、非凡、魔都三个来源，保留用户后续自行添加的配置。
- 完成资源站海报墙、分类、跨源搜索、详情选集、播放器和基础错误提示。
- 保留收藏、观看历史、断点续播、字幕、全屏和键鼠操作；用户数据与程序目录分开。
- 修复首次运行强制填写配置、字幕加载后不可见、快速加载配置导致重启首页空白等问题。
- 交付自带私有运行时的便携包，并在后续上传到私有下载仓库。

这个版本解决了“拿到即可选片播放”的基础问题，但首页仍由资源站目录驱动；后续按用户反馈调整。

### 0.2.0：把首页和跨源播放逻辑改正确

日期：2026-11-05。

- 首页改为豆瓣近期热播，分电影/电视剧，显示海报和真实评分；原资源站目录移到“资源”页。
- 默认来源由3个扩展到32个：保留原三个来源的稳定key，增加参考项目公开列表中的29个HTTP/API来源。
- 点击推荐或搜索结果后，自动查找来源、核对片名/年份/季数，排除解说、预告等不匹配内容。
- 首个通过检测的候选即可进入播放器，其他来源后台继续发现，支持手动切换。
- 增加真实解码失败和启动超时后的自动回退，按同集保留进度。
- 将豆瓣影片身份与最后成功播放来源分开保存，修复电影清晰度被当成集数、切换到另一集沿用旧进度等问题。
- 每次打开新来源都必须看到本次新视频帧，不能使用上一来源的累计帧判定成功。
- 修复豆瓣海报请求头与尺寸回退；推荐服务失败时使用明确标注的成功缓存或错误提示。
- 隐藏直播入口，本轮集中完善点播。

### 0.3.0：完善日常交互、选源偏好和频道布局

日期：2026-11-06。

| 改动 | 最终行为 |
| --- | --- |
| 视频点击显隐 | 单击视频可显示/隐藏整套顶部、底部、来源和媒体信息UI；暂停时也可手动隐藏。移动鼠标不会立刻推翻手动隐藏；双击仍切换全屏。 |
| 选集位置 | 普通窗口中的选集按钮放到下一集右侧，并验证选集列表可见、可操作。 |
| 来源耗时 | 自动显示ms或s；小于1秒绿色、1至3秒橙色、3秒及以上红色。这是媒体探测耗时，不是Ping。 |
| 来源状态 | NA只表示没有匹配影片；连接或媒体失败显示ERR，避免把缺片和故障混为一谈。 |
| 速度优先 | 尽快起播，HLS多变体时偏向较低带宽；备用候选参考实测探测耗时排序。 |
| 高清优先 | 最多等待6秒比较首批候选，优先清单分辨率，其次明确的线路/集名画质标记；站点品牌名称不能冒充画质。 |
| 卡片续播 | 海报内增加续播按钮和观看位置，保持海报排列齐整；季数从明确元数据提取，不凭空猜测。 |
| 历史兼容 | 搜索/资源记录有明确同名、同年、同类型时也可关联海报续播；保留原记录，不混合同名翻拍或明确不同豆瓣ID。信息不足的旧记录仍可从历史页打开。 |
| 媒体详情 | UI显示实际分辨率、编码、码率和封装；详情另列帧率、时长、大小与探测说明。暂停保留最后有效码率，新来源清零；未声明时使用的播放采样值会明确标注。 |
| 独立频道 | 豆瓣与Netflix标签片库分别保留分类、已加载条目和滚动位置，方便以后继续增加其他平台入口。 |
| 滚轮加载 | 向下滚动到底部附近自动加载一批，仍保留手动“加载更多”；切分类、频道、播放器或其他页面后恢复列表和位置。主动刷新只刷新当前分类。 |
| 弹幕说明 | 明确现有XML/JSON直链、本地文件和源自带数据能力，没有把网站主页或影片网页当作可直接加载的弹幕接口。 |

本版未增加、删除或替换现有32个播放来源，来源key保持不变。

## 四、主要问题的原因与修复

| 原问题 | 查到的原因 | 修复 |
| --- | --- | --- |
| 首页按资源站显示，不符合选片方式 | 推荐首页与单个资源站目录绑定 | 独立推荐页面；资源站目录保留为单独资源页。 |
| 来源只有三个 | 首版采用三个来源验证播放链路 | 扩展32个公开API入口并逐项报告当次结果。 |
| UI只能等自动隐藏 | 单击只调用显示；鼠标移动也会重新唤醒；来源面板在控制层外 | 增加明确的点击切换状态，将面板纳入整体控制层。 |
| 切页后瀑布流变回20部 | 分类切换清空列表，返回首页可能重建页面 | 为每个频道/分类保存进程级列表、页码和滚动位置。 |
| 看过后海报没有续播 | 观看状态没有绑定到每张卡片，部分搜索/资源记录没有豆瓣ID | 卡片绑定观看状态；对明确同名同年同类型记录做安全关联。 |
| 切源可能误判成功 | 播放器累计帧数包含旧来源 | 按每次打开的代次及新增视频帧判断，新源未成功不能覆盖好进度。 |
| 暂停后码率消失或换源沿用旧值 | 播放采样暂停时归零，缺少每次打开的独立状态 | 保留本来源最后有效值，新来源清零，并区分声明值和采样值。 |

## 五、实际验证到什么程度

### 自动检查与构建

| 版本 | 通过的行为断言 | 构建 |
| --- | ---: | --- |
| 0.1.0 | 23项 | Release x64，0警告、0错误 |
| 0.2.0 | 50项 | Release x64，0警告、0错误 |

断言覆盖持久化、字幕文本、影片匹配、媒体前缀检查、取消/并发、季集进度、HLS变体、延迟显示、频道状态和历史兼容等逻辑。断言数不代表相同数量的完整实机播放场景。

### 实机与发布验证

- 首版实播电影《星际穿越》和剧集《庆余年第二季》，验证暂停、快进、拖动、上下集、全屏、字幕文字及重启续播。
- 0.2.0从豆瓣电影/剧集卡片自动起播；手动换源保留同集位置。隔离坏源能通过轻量媒体检查但无法解码时，程序实际切到下一来源并出画面。
- 0.3.0实测滚轮将20部加载到40部，切到Netflix再返回后数量及位置保留；从播放器返回首页仍保留列表并显示续播。
- 实测播放和暂停状态下点击显隐UI；来源列表显示真实ms/s、颜色和NA/ERR；选集按钮位置正确。
- 最终包高清优先续播实际渲染1920×800、h264、25fps，保留原集进度。暂停后保留3.93Mb/s播放采样码率；约1.29GiB大小明确标为估算。
- 对12个分类入口逐一请求，都返回影片条目；Netflix条目核对到平台标签。
- 0.3.0播放测试前对系统默认输出静音并回读确认。
- ZIP检查包括完整性、当前程序集、默认配置、实体解码组件、唯一入口及无开发者配置/收藏/历史/日志。便携包、对应源码及校验文件从私有GitHub完整回下载后，SHA-256与本地一致。

历史来源样本检查中，32个入口当次有8个同时通过固定电影和剧集样本；某部推荐剧在其他验收中发现了十多个候选。这些是不同影片、不同时间的结果，**不能推导为全部32个来源始终有效**。

| 全来源长时间播放、所有编码/音画同步 | 未完成全面验收。 |

第三方媒体可能包含水印、片内广告或缓冲。豆瓣评分用于评价影片，不代表当前来源的画质评分。HLS通常没有单一文件的精确总大小，估算值不当作精确文件大小。会话内瀑布流保留到程序关闭，不承诺重启后恢复全部已加载列表；收藏和观看进度则会跨重启保留。

## 七、当前文件、升级与下载

本地可执行文件：

```text
D:\tvboxwin\artifacts\TVBox-x64-0.3.0\TVBox.exe
```

便携压缩包：

```text
D:\tvboxwin\artifacts\TVBox-x64-0.3.0.zip
```

当前ZIP为222,448,654字节，约212MiB（222MB）；解压后约524MiB（549MB）。体积包含私有.NET运行时、WinUI依赖、FFmpeg和Node等组件。完整解压后运行根目录EXE，不要只复制主程序。

升级前退出旧版；新程序继续使用原用户数据目录：

```text
%LOCALAPPDATA%\TVBox PC
```
