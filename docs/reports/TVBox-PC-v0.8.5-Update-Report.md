# TVBox PC v0.8.5 更新报告

版本：0.8.5。日期：2026-11-07。Windows 11 x64。本次继续0.8.4预览的原生验收，并修复验收中发现的问题。0.8.4已发布的报告与二进制保持历史原样；本报告补充解锁后的实际结果。

## 已实现与修复原因

1. **分季搜索拼写**：TMDB季卡片生成“第1季”后，原先直接把它作为资源站关键词；非凡和魔都的搜索接口对该写法返回0条，对“第一季”分别返回2条和1条。现将中文季名、原写法和基础片名组织成最多3次查询。基础片名只放宽查询，候选仍严格核对原片名/别名、年份、影视类型及季数，不能借此混播另一季或解说。
2. **旧失败缓存兼容**：使用`season-query-v2`缓存身份并纳入作品/季身份。旧拼写产生的失败记录不再阻止正确查询，旧的成功记录可继续采用；新规则下真正失败的结果仍正常缓存。保留旧文件、观看进度、来源统计和原站点key，不清空用户配置。
3. **冷启动横幅**：原来横幅与海报墙共用先进先出队列，且首张准备超时后，计时器在“尚无横幅”分支直接返回，可能一直空白。现让横幅请求优先排队；共享查询若已经排队可提升优先级，仍保持最多2项元数据并发。首次准备失败后延迟重试，保留12秒单次准备上限和8秒轮播，不新增无限并发。
4. **失败后停止转圈**：选源全部失败时只打开错误条，却没有关闭加载遮罩。终态错误现在同步结束缓冲标志并隐藏加载动画，保留刷新/手动重试入口。
5. **缺Logo文字兜底**：装饰图片的字符串加载分支忽略了“无占位图”设置，缺出品方Logo时仍显示电影图标。现统一遵守装饰属性；缺Logo的公司用名称文字卡片兜底。字符串图片控件重新加载时也会恢复未完成的图片读取。

## 已实测

- **离线回归：323项行为断言＋1行汇总**，比0.8.4新增11项：前台优先/并发上限、共享请求提权、取消释放、中文季名与查询上限、跨季拒绝、十二季写法、电影别名保持、旧失败缓存兼容、新失败继续缓存、特别篇身份隔离。不是323部影片或323个原生场景。
- **严格构建**：Release x64零警告、零错误。
- **首页**：1069×615普通窗口和1440×852最大化均保持紧凑横幅；独立宣传背景、海报外双评分、版本日期可读。观察自动轮播到不同影片；冷缓存的0.8.5隔离资料目录也成功显示并继续轮播。网络慢时仍可能等待，不承诺瞬时出图。
- **电影详情**：1985年《吸血鬼猎人D》实际显示宣传背景、中文简介、真实出品Logo、2部官方系列作品和动画电影优先推荐。外层滚轮在推荐区滚动后，18条扩展到36条；页面小型艺术标题居中置顶。公司无Logo时文字兜底已在普通窗口确认。
- **剧集资料**：《绝命毒师》第一季7集切到第二季13集，截图、简介、单集TMDB分数和续播提示正确变化，不把第一季的合成QA进度当作第二季进度。点击第二季指定集正确进入该季选源；改动前该测试未找到可播来源，不计为播放成功。
- **默认来源电影实播**：《肖申克的救赎》由魔都来源实际出画面，1920×1080/H.264，进度从约01:09继续前进到01:33后暂停。13条“媒体检测通过”仅是候选数，不代表13条都已实播。该场景在0.8.4验收实例完成，0.8.5未改媒体解码器。
- **修正后指定集实播**：在保留旧失败QA缓存的0.8.5隔离目录，从《庆余年》第一季第2集截图进入播放，自动选择魔都“第02集”，实际1920×1080/H.264出画面并持续前进超过1分钟。返回首页仍在后台播放，图片续播卡显示`S1 E2`、该集名称、剩余时间及进度。不是仅验证配置加载或HTTP成功。
- **全不可用场景**：仅在`.tools`中的专用测试副本，把32站API改为不可用的回环地址；32/32完成后显示明确错误且不再转圈。发布包默认配置未做该修改，未把故障夹具当正常片源实播。
- **静音与数据保护**：每次原生启动前均回读实际`TVBOX_PC_DATA_DIR`，使用`.tools`独立QA目录；播放前执行默认系统输出静音并回读成功。未写入真实用户观看记录、收藏或统计，未自动终止任何交互式TVBox进程。测试实例的正常窗口关闭记录不作为客户端崩溃。

## 已知限制、后续工作

- 豆瓣搜索接口本轮出现HTTP403，切换TMDB目录可继续检索；自动回退尚未在本版实现。TMDB按整剧组织季，搜索基础剧名后再选季更可靠。
- 用户随后新增的“刷新偏好不停播并列候选”“10站并发”“末路兼职/谷雨命名与缓存复现”“弹幕服务可配置”“Cloudstream/Nuvio与小雅/G-Box/WebDAV”属于下一轮工作，本版不冒充已经完成。
- 本版季名修复不能代表所有站点/所有命名格式都已兼容；`S1EP01`、绝对集号、跨季合并及来源暂时离线等需继续逐项验证。真实接口仍会有DNS、TLS、403或内容缺失。
- 默认来源电影中观察到内嵌广告文字；本版未移除烧录在画面中的广告，未宣称任何站点无广告。播放器弹幕在隔离默认设置中未启用，因此本次实播不代表弹幕覆盖验证。
- 未覆盖所有DPI、全部影片、长时间运行、HDR/4K、显存/内存峰值；标题为轻量图片纵深效果，不为每部片子生成3D模型。外挂字幕、多音轨和倍速的未验收状态不改变。
