# TVBox PC v0.8.4 更新报告

版本：0.8.4。日期：2026-11-07。平台：Windows 11 x64。此版为界面与资料功能预览，原生视觉/交互验收尚待桌面解锁，不替代已验收版本作为Latest。

## 本次已实现

- **首页紧凑横幅**：固定256逻辑像素高，不再根据窗口高度放大成大块海报。背景使用同一作品独立的横向宣传图，配合渐变遮罩；没有横向图时只保留渐变，不把海报放大充当背景。右侧130×182海报和海报外双评分，左侧艺术标题与简短介绍，底部保留1～5选择。
- **轮播进度**：此前切页等待元数据/图片时暂停计时并启用不定进度条，呈现为蓝条缓冲。现在8秒倒计时始终为确定进度，显示2秒后预取下一部；每次准备最多等待12秒，等待期间保留当前作品。切换成功重新计时，失败后延迟重试；离页、切平台或快速选择会取消旧请求，不无限占用前台。
- **跨启动海报缓存**：除已有图片磁盘缓存外，持久保存已经选定的中文海报、透明标题和横向图，重新启动先读取这些结果，再在后台补齐评分/资料。中文选图结果保存30天，其他已完成选图3天，暂未完成结果短缓存；手动校正的作品关联优先。旧版图片缓存路径继续兼容。文件解码成功后才写入缓存，拒绝HTML错误页，损坏缓存可失效重试；近期读过的图片更新时间，降低自动清理误淘汰常用海报的概率。
- **版本信息**：左侧设置上方显示程序实际程序集版本和发布日期。此版为`v0.8.4 / 2026-11-07`。
- **标题层次效果**：透明艺术标题加入轻量投影、错层和鼠标透视/视差；指针离开恢复，不运行常驻3D渲染循环，遵循系统动画设置。没有透明标题时仍在选图结束后一次显示排版文字，不先文字再闪换图片。此效果是平面图片的纵深表现，并不等于为每部片子生成真正的立体字模型。
- **详情连续布局**：独立大幅横向背景和渐变柔化，缺背景才用海报兜底；下方排列海报/资料、季、单集、出品与播出、简介、人物、资源、系列和推荐。移除旧的四个详情分页面。向下滚动后，小型艺术标题在顶栏居中显示。
- **季与单集**：同一详情内直接列季卡片，选择季后加载这一季的单集截图、名称、简介、时长、日期及TMDB单集评分。缺分用`-`，不恢复IMDb评分。点击单集带着明确季数/集数进入既有选源流程；各季及特别篇进度身份隔离。详情续播提示随所选季变化。
- **出品与系列**：读取真实出品公司/播出平台Logo以及TMDB官方电影系列。无官方系列时可列同名相关版本，并明确它们不等于已经确认的同系列；不同年份、电影/剧集仍是不同作品。
- **推荐顺序**：先读取实际TMDB相似作品，再查询题材目录。动画电影先同题材动画电影、再其他动画电影、再同为电影的相关题材与其他电影，最后扩展剧集；动画剧集同理。普通电影/剧集也优先保持类型。每个阶段分页，当前阶段仍可查询时不能抢先跨类型；最多查询服务允许范围内的50页/阶段，空页一次最多扫描3页。推荐卡片及“继续推荐”处于同一外层滚动区，支持向下滚动续载，不再嵌套纵向滚动条。
- **继续观看图片卡**：首页显示实际已看集的横向截图、片名、S/E、单集名称、已看时间/剩余时间和进度条，最多8项。没有单集截图时回退同作品横向图，再回退海报。后台补图只更新预览与元数据缓存，不改写观看时间或观看排序；仍先进入详情，避免误触即播放。
- **搜索辨别**：默认关键词排序先精确片名，再在相近片名内优先已上映作品，避免未来计划项目盖过老电影；明确选择年份/评分/名称等排序时保留用户排序。截图中的2027年《吸血鬼猎人D：复活》和1985年电影不能强行绑定为一部。

## 原因与数据保护

此前缓存只保证图片文件复用，初次呈现仍可能等待元数据重新决定中文图片；此外首页高度跟随窗口可用高度、详情按页签隐藏内容、相似推荐只取宽泛题材，分别造成横幅过高、资料不可直见和跨类型推荐。本版分别调整布局、展示流程和推荐分层，不通过删除收藏、历史或设置解决。

新增元数据字段及缓存均为兼容性扩展；旧收藏/历史可继续读。现有默认配置身份、32个片源key和播放探测协议保持。清除错误TMDB关联会同时清除该错误资料带来的季、出品方及系列，保留用户收藏与进度。

## 实际验证

- 离线回归：**312项行为断言＋1行汇总**，比0.8.3新增27项断言，包含真实子进程重启读取选图/图片、无效缓存、显式改绑、分季身份、真实单集字段、类型优先级、推荐分页/取消、默认搜索与手动排序、续播卡片不改进度。不是312个影片或原生操作场景。
- Release x64严格构建：零警告、零错误。
- 真实联网资料验证3项断言：1985年电影TMDB `movie:9463`返回中文简介144字、横向背景、3个出品方Logo、2部官方系列作品；剧集`tv:1396`返回6个季条目（含特别篇）、第一季7集，首集有截图、中文简介和TMDB单集评分；该电影首批18条推荐全部为动画电影。
- 已用实际`TVBOX_PC_DATA_DIR`在`.tools`独立QA资料目录启动原生预览，只放公开固定作品和合成观看进度；无障碍文本能回读版本/发布日期、续播卡片的S/E与剩余时间。
- **原生视觉与交互尚未完成**：截图实际为Windows锁屏，无法确认横幅裁切、透视观感、固定标题、季/单集点击和外层滚动手感；没有将无障碍树或编译成功当作视觉验收。本轮未重新播放视频，因此未触发播放测试静音步骤，也不宣称本版单集真实出画面验证通过。既有交互式实例未被终止。

## 已知限制与遗留

- 冷缓存中文图仍取决于资料接口、可靠作品匹配与图片网络，不能保证所有作品立即出图。默认图片缓存上限1GB，可在设置修改；自动清理、手动清缓存、文件损坏或匹配改变后可能需要重新下载。不是无限保存承诺。
- TMDB Key仍可选，不填写不影响原有普通选片播放；丰富季/单集、公司、系列及TMDB相似资料依赖该Key与上游覆盖。角色名、部分单集名和季海报可能只提供原文；不编造中文资料或评分。
- 1985年电影本次接口未提供中文透明标题，使用英文透明标题兜底；没有将2027年未上映项目的空白资料替换成1985年剧情。
- 推荐分页和排序覆盖当前接口可查询范围，不声称穷尽全球片库。未验证所有作品、全部DPI、HDR/4K、长时间运行与内存峰值。
- 解锁后仍需完成视觉/鼠标交互及一部电影、一部剧集指定集的静音实播验收，确认后才能提升为正式Latest。网盘/高清资源设计沿用0.9.0文档，本次未接入NAS或私有云盘。

- 桌面独立目录：`%USERPROFILE%\Desktop\TVBox-PC-0.8.4`；保留原版目录，避免覆盖正在运行的版本。

- 附件包含便携ZIP、完整对应源码ZIP、本报告独立MD、既有高清资源设计MD与SHA-256校验单；远程交付完成以附件完整下载/哈希校验记录为准，链接本身不是校验成功证据。
