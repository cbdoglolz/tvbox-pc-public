# TVBox PC v0.8.1 更新报告

日期：2026-11-07。Windows 11 x64。基于0.8.0，保留用户资料与默认来源身份。

## 已实现与修复原因

### 1. 选中残留、渐变与Netflix动画

0.8.0同时使用代码设置ListViewItem本地Background和控件自身的选中视觉状态。切分类重建/复用容器时，两套状态没有同步，造成旧项仍有紫色框。原验收只观察了初始反差，没有充分覆盖连续切换，漏掉了这个问题。

本版删除手动涂选中背景的逻辑，由模板直接绑定`IsSelected`，每组只有一个选中层；悬停层独立，不冒充选中。选中使用三段紫色渐变，深浅主题的选中文字保持可读。

Netflix原图是大幅JPEG，在小容器中裁切后又放大，字标被截断。现改为完整SVG字标。选中时做横向伸展、Y轴翻转转正与轻微回弹，最终仅约1.04倍，留有安全边距；动画1050毫秒，关闭系统动画时静态显示。该动画由程序实现，是品牌风格的轻量变换，没有嵌入官方开场视频或声音。

资产逐项变化：新增`assets/icons/netflix-wordmark.svg`；删除已无代码引用的`assets/icons/netflix-wordmark.jpg`（旧文件211011字节）；原`netflix.svg`的N标志与其他平台标志未变。标志来源及商标说明已更新到THIRD-PARTY-NOTICES。

### 2. 逐年筛选

统一筛选组件现在按当年递减列出到1990年。本次为2026、2025……1990；再列2020年代、2010年代……1950年代、1950年以前，最后是自定义年份。

支持直接输入四位年份后回车，不必反复滚动长菜单；下拉配置了最大高度。精确年份与年代使用不同选项键，例如`y2020`表示2020–2020，`d2020`表示2020年至当年。选回已保存条件时按真实数值恢复，不会把旧“2000年以前”的1800–1999范围误变成1950年以前。

首页、分类、搜索共用此组件。首页条件作用于下方频道海报墙；今日发现五部仍保持当天固定，不随筛选重新抽取。

### 3. 横幅与双评分

横幅右侧海报放大，左侧剧情限制为两行，给海报更多空间；评分统一使用普通海报同一条评分组件，贴在海报外下方。海报高度按窗口可用空间在234～314间调整，较大窗口可到224×314，小窗口仍保留1～5分页数字。清除了栏目加载状态压在横幅文字上的情况。

海报、横幅、详情、资料弹窗和筛选的评分界面只保留豆瓣与TMDB。移除IMDb评分显示、主评分选项和评分过滤选项；旧IMDb筛选被使用时改回豆瓣，同时取消原IMDb阈值，避免把不同平台分数强行套用。年份、地区等其他条件保留。底层已有外部ID兼容字段未删除。

IMDb并非所有数据都收费：[官方非商业离线数据集](https://data.imdb.com/non-commercial-datasets/)包含评分；[官方实时API](https://data.imdb.com/documentation/api-documentation/getting-access/)通过AWS Data Exchange订阅。按用户只保留两种评分的方向，本次没有增加收费服务或庞大的离线评分库。

### 4. 中文海报优先

TMDB详情请求现同时获取图片资料，优先选择`iso_639_1=zh`标记的海报；没有可用中文图才保留原图。中文包含简繁体，按提供方标记判断，不做OCR猜测，也不会自动把外文海报上的字翻译成中文。

修复两段实际更新链：`ApplyMetadata`此前不更新海报URL/图片绑定，现在会更新并通知；20分钟内已补齐的卡片此前被直接跳过，刷新后可能重新显示列表原图，现在会重新应用缓存的中文图。已有可靠中文图也不会被晚到的普通资料降级替换。当天发现记录同步保存新海报，保留原五部身份和顺序。

已有缓存通过新增ArtworkSchema识别并逐步补齐，没有清空原资料库。TMDB增强仍需要可选个人Key；不填时继续显示已有豆瓣/来源图片，不阻塞普通看片。

### 5. 自动弹幕：匹配改进与覆盖边界

默认查询现会尝试显示片名、原名和可靠别名；识别“第二季/Season 2/数字后缀2”，不会把第一季的库附给第二季。播放器控制层显示等待、搜索中、已加载、超时、服务不可用或未覆盖，点击状态可打开弹幕菜单。修正旧菜单中“暂不支持自动匹配”的过期文案。

**《赛博朋克：边缘行者》第二季第一集的弹幕没有加载成功。** 已确认开关开启、未配置聚合服务；真实B站正片目录对片名及别名返回无匹配。本版原生播放器已显示“B站弹幕未覆盖本片本季；已检索别名，可配置多平台聚合服务”。这是当前来源覆盖不足，不能只修改UI就生成弹幕。

核查的公共聚合地址出现DNS、超时、401/403或证书不匹配；没有关闭证书校验或硬编码这些不稳定服务。本轮没有获得可用的用户聚合地址，没有声称该片弹幕已解决。已配置的兼容服务仍支持自动搜索/加载；未配置时使用B站。详见[弹幕专项说明](../ADS-AND-DANMAKU.md)。

## 实际验证

- **237项行为断言，另1行汇总**，相对0.8.0新增19项。覆盖逐年/年代范围与恢复、旧年份范围兼容、IMDb阈值迁移、中文图片优先及非法路径、图片绑定更新、防止降级、暖缓存刷新、取消后的晚到更新、第二季别名与避免串第一季、别名自动重试。断言数不是237个独立实机场景。
- 严格Release x64零警告零错误；正式便携包从干净提交构建。私有.NET运行库和原依赖版本不变。
- 原生连续切换热门剧集→热门电影→最新剧集，以及豆瓣↔Netflix，旧项背景消失，每组只留一项渐变；白色与深色主题均观察到完整Netflix字标及可读文字。
- 原生小窗口已看到放大后的海报、海报底下的双评分和1～5数字；较大的314上限未覆盖完整DPI/分辨率矩阵。
- 原生年份菜单显示2026、2025、2024等逐年顺序；实际输入2025并回车，出现2025–2025条件标签，页面未跳走。
- 真实TMDB图片请求返回`zh`海报和ArtworkSchema=1。列表更新、缓存回填、防止中文图被替换由行为断言验证；原生海报与详情观察到中文海报及双评分。
- 用户指定作品第一集在隔离QA进程中从`builtin_360`（360资源）实际出画面，观察到1920×1080/H.264/HLS。统计记入一次速度胜出，实际最高高度1080，首帧约3.83秒；没有把媒体探测当播放成功。
- 同一原生场景明确显示弹幕未覆盖原因，没有加载第一季弹幕冒充第二季。B站原有可匹配正片的成功路径在0.8.0已实测，本轮未重复把该结果当新覆盖数量。
- 启动原生QA前回读实际`TVBOX_PC_DATA_DIR`为.tools下独立目录；播放前默认系统输出静音并回读确认。未清空用户资料或通过结束交互式进程清理环境。

## 未验证与遗留事项

- Netflix动画是程序实现的伸展/翻转效果；未对照官方开场逐帧复刻。实机核对了切换和完整字标；最终1050毫秒时长、最初等待片源状态文案为本轮后续小改，未另起原生进程复验。
- 没有可用聚合地址，因此指定动画的弹幕仍未解决；优酷真实弹幕、多平台服务部署和官方应用授权未完成。自动搜索不等于所有作品都有弹幕。
- 图片语言标记依赖提供方。无中文图、没有个人Key、资料请求失败或无可靠作品关联时仍可能显示外文海报；不能保证全墙每张图都是中文。
- 年份长菜单已提供直接输入与滚动；未覆盖全部DPI、触摸屏和所有键盘组合。未实测所有1990～2026选项的每个远程结果。
- 本轮不是全部32站、长时间运行、全部季/集、HDR/RTX或广告过滤验收；不承诺彻底消灭所有闪退。

## 来源、栏目与用户数据

32个默认点播来源、来源key、订阅地址均未新增、删除或修改。豆瓣、Netflix、TMDB既有栏目的名称和稳定标识均未变更。没有新增默认公共弹幕服务。评分UI删除项的稳定标识是`imdb`，保留`douban`与`tmdb`。

升级不清空收藏、历史、Key、订阅、筛选预设或每日发现记录。既有IMDb阈值按上文兼容处理；旧版目录可保留用于回退。0.8.0验收已逐字节归档为`docs/ACCEPTANCE-0.8.0.md`，原版本报告未覆盖。
