# TVBox PC v0.8.7 更新报告

版本：0.8.7　日期：2026-11-07　平台：Windows 11 x64。

本次交付以0.8.6为基线，完成播放器交互、弹幕、站点管理及观看状态的修改。**国际站点只是默认关闭的实验适配，网盘/G-Box尚未接通；不能把它们当成已验收的高清播放功能。** 上版验收原样归档在[ACCEPTANCE-0.8.6.md](../ACCEPTANCE-0.8.6.md)。

## 本次已实现

### 播放器与弹幕

- 删除顶部重复弹幕入口，底部相邻保留“开关”“弹幕源”两个按钮，普通窗口和紧凑布局一致。
- 弹幕源面板显示加载结果、候选与重试，提供B站、弹弹play、优酷网页入口。网页入口用于查询，不代表任意网站弹幕都能直接自动抓取。原可配置弹幕服务/官方API设置保留，公开包不含应用凭据。
- 字号12～44、粗体、原色/白/金/紫/青、0.5～2.5倍速度及占屏比例即时生效；默认顶部1/4，可选1/3、1/2、3/4、全屏。已显示的弹幕会调整，不需要重新搜索弹幕；暂停时也保留正确布局。
- 加载失败在“弹幕源”旁保留黄色感叹号，点击查看具体状态；开关和加载通知改为画面中央，普通通知显示8秒，可关闭；播放错误保持到关闭，避免与顶部片源状态重叠。重复消息去重并有限排队。
- 加载/恢复播放的遮罩也接收单击唤醒/隐藏控制和双击全屏，修复遮罩吞掉视频点击的路径。该特殊时点尚未直接完成原生点击验收。
- 侧栏正在播放名称使用明确的季、集字段；点播最小缓冲由0.5秒提高至3秒，预读30秒，直播仍保持0.5秒。统计真实缓冲次数与时长，并在媒体详情/提示中给出依据。

### 站点、广告标记与选源

- 左侧新增“站点”：列出原32站点和3个实验站点，单独/按当前分组全部开关、分组、添加MacCMS JSON站点、本地移除/恢复、复制接口、跳转网页。停用同时作用于资源搜索和自动选源，排队任务及迟到结果也检查开关；当前已播放的视频不因开关立即停止。
- 原站点移除是本地覆盖，原订阅身份、收藏和历史不删除；后续可恢复。
- 当前播放来源、播放器选源列表和详情来源列表提供广告标记：金色问号=未标记，红色恶魔=有广告，双翅=无广告。图标本地绘制，不依赖系统Emoji字体。
- 标记按“作品＋季＋站点”保留；自动选源先查未标记/无广告来源，确无可用替代时保留有广告来源兜底。手动切源仍可选。下一集重新使用统一季集身份；不是用过滤广告切片的方法删除视频内容。
- 设置页汇总各站有广告/无广告标记次数，一季记一次，不按每一集重复累加；这不是按真实广告秒数的自动检测。
- 媒体探测总预算由6秒改为20秒、单跳8秒，减少合法多跳HLS被过早剔除；明确报告“匹配但HTTP403/404”“返回网页而非媒体”，不把它们误报为没有匹配片名。

### 海报、详情与继续观看

- 继续观看增加垃圾桶与清空确认、每张卡左上圆形×；只隐藏该栏入口，历史和断点仍保留，后续主动播放可重新出现。增加鼠标左键横拖，区分拖动与点击。
- 工作/单集可以标记正在看（紫色眼睛）、已看完（绿色勾）或清除标记；实际播放保存各季各集位置，海报显示观看状态。手动状态优先，已有资料不会清空。
- 单集封面显示已保存的分钟秒数和半透明继续播放按钮；按钮续播，点击封面本身从头播放。详情主播放按钮继续使用作品的最近进度。
- 季和单集没有截图、或图片加载失败时回退影片海报，不留下空白区域。
- 详情事实改为紧凑单行横向排列：完整基础片名、年份、类型、地区等，不截断片名或用大间距撑成两行；窗口窄时横向滚动。片名去季后缀，左键长按约650毫秒复制，并提示“已复制XXXX”。
- 出品/播出标志进入同一套目录筛选（公司或电视网），保留筛选身份及缓存边界。
- 豆瓣、TMDB和站点的外链统一为右上角断开的方框箭头图标。

### 主题、搜索与瀑布流

- 右上衣服替换为橙色太阳/深蓝月亮；显示当前主题，点击沿同一圆心顺时针转出/转入，560毫秒轻量合成动画。系统关闭动画时直接切换。
- 顶部搜索显示最多6个近期热门标题，可一行多项；保留最近10条搜索，单条×删除，左侧垃圾桶确认后清空。隐私模式不新增记录。
- 修复搜索历史提交后弹窗因焦点再次触发而弹回：显式请求才展开，提交后阻止内部焦点重开。
- 首页、目录、详情长列表右侧提供向上箭头；回顶后向下箭头返回刚才位置，已经加载的条目保留，不重新缩成20条。

## 原因与诊断结论

1. 弹幕入口分散、提示在顶部叠加：入口合并，中心提示排队，失败状态留在底部按钮。
2. 缓冲频繁：FX战士久留美第2集360/猫眼各取3个完整分片。360的2秒片下载约2.734/2.938秒，3.6秒片约3.547秒；猫眼2.085秒片约2.563/2.719秒，2.92秒片约3.109秒。部分供给低于实时播放需求，加上原0.5秒缓冲很容易耗尽。提高缓冲能吸收波动，**不能补足长期不足的上游带宽**。列表中存在时域断点，不据此断言它就是这次卡顿原因。
3. 《幸福伽菜子的快乐杀手生活》S1：32站核对，电影天堂/暴风/优酷/如意匹配到2025第一季，但首集实测媒体403（三站）/404（暴风）；部分其他站只有S2。本版保留严格季集身份并展示错误，**没有通过改成第二季伪装修好，S1目前仍未实播**。
4. 本轮原生验证发现新站点页以纯代码Page导航会导致进程崩溃；改为XAML注册的partial Page，重新进入站点页、切开关保存已通过。此结论针对这个已复现入口，不代表对所有历史闪退作出单一归因。

## 实际验证

- **离线396项行为断言＋1行汇总**，不是396部影片或站点。新增覆盖逐集断点、状态重载/隔季、继续观看隐藏不删历史、搜索10条/去重/删除/清空、公司/电视网身份、站点开关/移除/分组、广告首选与唯一广告源兜底、探测慢多跳/HTML拒绝/真实错误、国际字幕请求头/并发上限与取消、侧栏明确季集。
- 独立更新助手**4个安装/失败回滚场景**；严格Release x64构建零警告、零错误。编译/探测通过不替代播放。
- 原生隔离测试实际使用`TVBOX_PC_DATA_DIR`指向`.tools`目录；每次播放前系统默认音频输出静音并回读确认。没有清空日常用户资料，没有强制终止任何共享交互实例。
- 国内极速来源《肖申克的救赎》实际解码1280×720 H.264并出画面，进度01:00推进至04:16；B站真实加载9,600条弹幕，顶部1/4显示，底部面板打开、粗体即时修改并保存。
- 原生确认站点页正常进入、360开关持久保存；主题太阳/月亮双状态；近期热词/历史搜索返回7项、提交后弹窗保持关闭；Castle Rock出品方查询真实返回20项；列表回顶与返回原位置；继续观看清空确认取消后保留原卡片。
- 包体按标准多文件便携布局构建，纯净扫描、ZIP CRC/源码与报告一致性、私有运行库入口及发布附件完整下载按交付流程核查。

## 未完整验证与限制

- 广告标记后的长时间连续多季播放、每个弹幕外观组合、正在恢复进度遮罩的准确点击时点、所有单集封面/续播/鼠标拖动组合，尚未完成完整原生回归；对应代码/离线验证不等于原生已验收。
- 360/猫眼上游带宽、S1失效媒体地址、国际站点403仍可能影响观看；没有保证任何第三方服务持续可用。
- 没有对所有32站/全部作品做实播，不承诺永不闪退或不卡顿。4K/HDR/RTX5080长播、DPI/多屏及无系统.NET的另一台干净电脑仍未完整验收。
- 继续观看移除不清除历史；标记有广告不会擦除已经嵌入视频的赌博画面。网页弹幕入口不等同于新增全站解析能力。
- G-Box/网盘凭据界面与协议接入仍是遗留工作，本版没有提供已连接的假入口。
