# TVBox PC v0.8.0 更新报告

日期：2026-11-07。适用：Windows 11 x64。上一交付版本：0.7.0。

## 本次已实现

- **今日发现五部轮播**：每个平台每天固定五部，数字1～5居中，顶部进度条每8秒走完后切下一部并循环。保存当天顺序，重启读取原记录；优先避开前10天已展示作品，候选不足时明确提示部分重复。首次获取最多扩展四页电影和剧集，足够后提前停止；保留最近11天记录。
- **首页统一为分类海报墙**：移除下方重复的分组推荐及其“查看更多”。顶部分类决定下方内容，继续使用已有瀑布流和页面状态保留机制。正常页底部不再固定显示“加载更多”；网络失败时显示重试按钮。
- **海报与详情**：删除白色圆圈信息图标；三平台评分移到海报外下方。详情新增观看进度，复用季/集/时分秒规则。相似推荐移除内部滚动限制，由详情外层统一滚动，向下滚动追加；“继续推荐”按钮位于推荐列表之后，可正常滚到。
- **选中反馈**：平台标志选中时轻量缩放约12%，动画220毫秒；平台和分类使用更明显的紫色选中背景。尊重系统关闭动画的设置。
- **实际开播统计**：设置新增片源统计。每个播放会话中每集首次实际出画面记一次胜出，区分速度/高清偏好，累计播放连接尝试、失败、平均首帧时间、实际最高画面高度；同集换源不重复计胜。媒体探测通过不计为开播。分辨率晚于首帧到达时补记，不额外计胜。
- **片源测试缓存**：按配置、片名、年份、类型与集数保存站点测试结果，有效期7天。有已知可用站时优先仅测试这些站，跳过历史失败/未验证站；播放器实际失败后更新记录。没有仍有效的成功站时，允许未测试站参与；播放页刷新或明确手动选源可绕过缓存重测。
- **缓存自动维护**：默认启用，上限1024 MiB，每5分钟检查，超限后按旧到新清理至约80%；保护最近2分钟写入、跳过重解析目录。仅清理可再生成的cache目录。收藏、历史、凭据、设置、统计和每日发现不在清理范围；影视资料SQLite保留既有128 MiB维护规则。
- **真正自动搜索弹幕**：设置启用弹幕时同时启用自动搜索/显示，当前正在播放的影片也会重新查询。优先站点自带弹幕，无内容时按片名和集数匹配B站正片；可选填兼容弹弹play的聚合服务接入优酷等平台。切集/切源取消旧请求，晚到结果不能串集。成功结果缓存24小时，失败不阻塞播放。原先仅保存、没有查询行为的“自动显示”设置现在接入实际流程；保留已启用自动设置的用户意图。
- **广告方案核查**：新增[弹幕与广告专项说明](../ADS-AND-DANMAKU.md)。本版没有宣称可以自动抹除烧录赌场文字，也没有全局删除HLS不连续分片。

## 修复原因

原首页同时存在顶部分类和下方同名推荐组，导致内容入口重复；评分位于海报内部，遮住了图片。详情推荐设定内部最大高度，叠加外层ScrollViewer，产生两层滚动争抢。原弹幕设置的自动开关没有搜索调用路径，用户开启后也不会自行找弹幕。

本次移除重复布局与推荐请求，统一推荐滚动归属；将弹幕加载改为独立可取消任务，并在提交时检查当前播放代次，避免旧集覆盖。统计以真实渲染帧和本集续播恢复状态为依据；首帧与媒体资料不同步的问题使用后续回读补记。

## 实际验证

- **218项行为断言，另1行汇总**：比0.7.0新增29项。覆盖每日五部/十天避重/冷数据库重开、候选不足、缓存实际跳过站点与显式重测、统计与晚到分辨率、无痕、缓存删除保护、弹幕协议和自动搜索到评论的完整HTTP夹具链路、歧义与取消。断言数不等于218个独立实机场景。
- 严格Release x64构建零警告、零错误。便携发布继续使用项目Build/Publish脚本，包含私有.NET运行库；用户状态文件和新增统计文件纳入发布排除检查。
- 原生首页观察到五个分页数字、进度条和轮播；点击第1部后内容与选中数字改变。新选中背景反差、评分在海报外、信息图标删除均已观察。
- 原生详情相似推荐从19部追加到39部；鼠标在推荐区内部滚动即可到列表后方按钮，并触发下一页。
- B站真实接口搜索《武林外传》2011电影版，匹配正片cid并解析**9600条**弹幕。配置启用弹幕的独立QA原生播放器中，自动选源出画面后，弹幕直接随视频显示，没有粘贴弹幕链接。
- 测试影片从非凡资源（`builtin_ffzy`）实际出画面，观察到1920×838、H.264、HLS，播放超过1分钟。统计文件实际记入1次速度胜出、1次连接，首帧耗时约6.52秒。该耗时从解析/起播尝试计起，不等同于站点HTTP测速。
- 每次原生播放测试前，系统默认输出静音并回读确认；启动前回读实际`TVBOX_PC_DATA_DIR`为项目.tools下隔离目录。未清空用户资料，也未通过终止交互式进程清理QA环境。

## 未做、未验证与遗留事项

- 未实际等待11天；每日避重和重启稳定性以持久化夹具证明。当天五部按本机日期/平台固定，候选不足会明确降级。
- 分辨率晚到补记、同集不同名称去重、首页最后一项按钮收敛已经实现并通过对应代码/回归/构建核对；未用包含这些最后补丁的新原生进程逐项复验。
- 未填满1 GiB并实际等待后台周期；未覆盖全部32站真实播放、全部剧集与季切换、数天连续运行、完整DPI矩阵。不能承诺消灭所有闪退。
- 优酷真实弹幕尚未验收；兼容服务完整链路通过夹具，不代表任意公共站可用。公共站核查出现DNS失败、403或超时，因此未强行设为默认。弹弹play官方接入需要应用授权，详见[官方要求](https://doc.dandanplay.com/open/)。
- 不自动给不确定的同名版本绑定弹幕；不同剪辑版可能有时间偏差。B站XML池不是全部历史弹幕；没有实现弹幕发送、登录或自动OCR去广告。
- 已烧录的赌场文字/视频无法靠DNS或网页拦截规则去掉。当前可换更干净来源；标记分片过滤、手动遮罩/跳过区间仍待后续按来源实测，详见专项说明。
- 小雅/G-Box、直播、复杂Spider兼容、HDR/RTX、AI、跨端同步和异机Runtime问题仍不在本轮范围。
