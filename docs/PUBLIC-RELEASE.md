# 公开源码、纯净发行包与更新渠道

2026-11-07起，公开仓库为：https://github.com/cbdoglolz/tvbox-pc-public 。原私有发行仓库保留，不改变其可见性，不把私有Git历史或旧附件批量转公开。

## 纯净交付

公开源码从当前已验收、已审计的跟踪文件建立全新Git快照；不复制本机`.git`历史、`.tools`、`artifacts`、运行目录、缓存或聊天附件。保留GPL许可和上游归属。公开提交使用GitHub noreply邮箱，不使用本机私人提交邮箱。

便携包从干净源代码构建，默认只含程序、运行库、公开默认来源和说明文件。禁止包含配置、收藏、历史、观看统计、日志、数据库、Cookie、Token、证书私钥、API Key及任何个人服务器地址。TMDB及其他个人凭据只在用户资料目录加密保存，不内置共享Key。

发布前分别检查源文件清单、文本敏感标记、ZIP成员和默认配置；公开后以无需登录的下载方式完整下载并核对SHA-256。没有扫描匹配不是数学意义上证明绝无敏感信息，仍须检查新增文件和真实变更。

## 更新入口的兼容范围

现有0.8.4/0.8.5 WinUI客户端尚无完整的在线更新器，不能在已经分发的二进制中凭空增加功能。首个带更新器的后续版本需要手动安装一次；此后由软件的“检查更新”读取本公开仓库的稳定Release。

后续更新器应后台下载、核验摘要并暂存，用户确认安装时正常退出后应用更新；不得通过强制结束交互式进程更新文件。失败应能恢复，升级默认保留用户资料。预览版与稳定版应区分，更新成功不能只以下载或配置加载成功判断。

GitHub Release是当前分发渠道；将来若增加自托管公网镜像，应保留相同的版本、文件摘要和纯净包规则。源代码公开不等于允许上传个人资料或认证信息。
