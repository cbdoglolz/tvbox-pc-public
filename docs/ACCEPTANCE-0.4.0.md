## 未验证和限制

- 无个人TMDB凭据：未执行真实认证后的搜索/discover、详情、自动关联、季选择联网及外链核验。使用fixture通过不能替代这些实测。
- 豆瓣最多1000条可查询候选、TMDB最多500页；提示“当前匹配”只代表已扫描范围。豆瓣接口与第三方片源未来可能限流/失效。
- IMDb只保留可靠外部ID及链接，本版没有合法IMDb分数服务；未知分不当0分。
- 查询与元数据存SQLite；原JSON收藏/历史仍为权威数据。新查询位置可跨重启保存，首页原推荐瀑布流仍为当前会话保留。
- 原普通来源的广告、水印、缓冲不可由探测成功排除；高清优先不是全网最高画质保证。
- 未执行长时稳定性、RTX5080/4K/HDR、直播、云盘、AI、MSI或自动更新验收。交付为未签名便携ZIP。
