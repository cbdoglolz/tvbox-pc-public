# 上游与本次开发

- 基础工程：blueberry2568/TVBox-for-Windows。
- 上游提交：`c7d0c43b9916ef6a62439be1e0649a212622739c`。
- 许可：GNU GPL v3；Flyleaf、FFmpeg、WinUI、Node 等分别遵守原组件许可，原许可证与来源文件随包保留。
- 原始 README 保存在 `docs/UPSTREAM-README.md`。
- ZxxXinI/tvbox 仅用于对齐开箱即用体验和发现公开 API 地址，没有复制其 Kotlin/Compose 源码。

本次主要改动：免输入的本地内置配置、独立用户数据目录、首页最新更新分类与继续观看、来源连接状态/重试/启动失败切源、最多三源并发搜索及逐源状态、默认启用 TLS 证书验证、跨进程持久化回归测试、构建入口与首版说明。

v0.2.0 改为豆瓣热播首页（电影/电视剧、海报、评分），原资源站首页移至资源页。参照原版公开的推荐入口与播放流程，独立实现 32 源匹配、真实媒体检测、首源起播/后台补源、解码失败切换及同集续播；未复制无明确许可的 Android 应用源码。具体核查点见 `docs/PLAYBACK-FLOW.md`。

默认配置身份和站点 key 保持固定，以便升级保留收藏与观看进度。更新程序包时使用包内新的默认配置，不以旧的网络配置快照覆盖它。用户自行添加的配置优先保留。

v0.3.0 新增点击显隐、媒体详情、探测耗时、选源偏好、卡片续播和会话级瀑布流。Netflix 页面展示的是豆瓣 Netflix 标签元数据与评分，没有通过 Netflix 账号取流或解密其付费媒体，也不冒充 Netflix 官方榜单。

v0.4.0 新增结构化分类查询、SQLite元数据缓存、资料详情、分平台评分和可选个人TMDB凭据。豆瓣与TMDB身份分开，不将IMDb外部ID视为评分数据。小雅/G-Box实际适配按用户要求延期，普通播放链路继续使用原32源及原稳定key。
