# TVBox PC

公开源码与纯净下载：[tvbox-pc-public](https://github.com/cbdoglolz/tvbox-pc-public)。个人配置、缓存、观看记录和凭据均不包含在发行包中。[公开发行及更新兼容说明](docs/PUBLIC-RELEASE.md)。

Windows 11 x64 点播客户端。v0.8.6增加公开稳定版在线更新、统一季/集匹配、10站并发检测、保留播放的后台刷新及可选弹幕服务；修复《肖申克》因B站上线日期被误过滤的弹幕。保留原32来源和个人资料，具体实际验证与限制见[0.8.6更新报告](docs/reports/TVBox-PC-v0.8.6-Update-Report.md)。云盘及国际高清扩展仍按[接入方案](docs/development/TVBox-PC-v0.9.0-HD-Resource-Integration-Plan.md)实施。

## 运行

完整解压便携包，运行根目录的 **TVBox.exe**。不要只复制主程序。

首次启动直接显示豆瓣推荐，不要求填写订阅地址、NAS 地址、账号或 AI Key。豆瓣页包含热播电视剧、热播电影、最新电影、最新电视剧、最新动漫与 TOP250。Netflix 页单独保留自己的分类、列表和位置，使用豆瓣 Netflix 标签片库及豆瓣评分，非 Netflix 官方榜单；它的末栏为“高分佳作”。最新分类按首播/首映时间排序，可能包含待播条目。海报缺失的评分显示短横线`-`；资源站内容只在独立的“资源”页浏览。推荐服务暂时不可用时优先显示明确标注的上次成功缓存。

向下滚动接近列表底部时自动加载一批，也可点击“加载更多”。关闭程序前，各频道/分类已加载的全部条目和滚动位置都会保留，切频道、切分类、打开影片或其他页面不会重置为20部。首页不再显示“刷新推荐”；滚动加载和分类切换保持原有行为。海报上的续播入口显示已保存的季数（片名包含时）、集数和时分秒。

从搜索/资源页开始观看的记录，有明确同名、同年及同类型元数据时也能关联到海报续播；信息不完整或明确不同豆瓣ID的记录不自动合并，原记录继续保留在历史页。

内置来源扩展为参考 Android TVBox 公开列表中的 32 个 HTTP/API 来源，保留原三个站点的身份。点开推荐或搜索结果后，最多10站同时搜索、读取详情并检查真实媒体，首个候选即可起播；后台继续补齐其他来源。续播先单独尝试上次成功来源，确认新画面和原进度后直接播放；失败才按偏好查找其他来源。播放页底部保留手动切源，顶部偏好更改后显示红色叹号，点击右侧刷新图标后台重新检测本季本集，当前视频继续播放；完成后从成功列表手动选择切换。实际起播还必须经过播放器解码和新视频帧检查，不能把接口返回成功当作播放成功。

播放中可以去首页、分类或设置操作，视频继续在后台播放。侧栏“正在播放”随时回到同一个播放会话。打开另一部片或退出程序才结束原会话。

新安装默认深海紫蓝主题，设置可切换浅色或随品牌变化（豆瓣浅色、Netflix深色）；旧配置升级保留品牌模式。Netflix使用官方横向Wordmark，豆瓣和TMDB保留官方标识。首页增加主推荐、继续观看和限量推荐行，频道海报墙继续滚动加载。组合筛选在当前页应用，排序方向单按钮循环“默认→正序→逆序→默认”；默认恢复栏目规则，不清条件。排序覆盖已检索候选，继续加载补全；“全部电影和剧集”指内容类别，不代表搜索所有播放源或NAS。

海报外下方按豆瓣、TMDB顺序显示独立评分，缺失用`-`。保存个人TMDB凭据后，已加载海报会在后台补齐TMDB资料（最多两项并发），无需先点详情；匹配失败保留`-`。IMDb目前没有评分服务，可靠外部ID仍可用于打开影片页面。

每个来源的可用性和片库不同，32 个配置入口不代表每部影片都有 32 个可用线路。搜索会核对片名、明确年份和季数，排除解说/预告等结果；没有匹配资源时明确提示，不自动播放名字相近的其他影片。来源是第三方在线服务，仅使用有权访问的内容。

程序文件与用户数据分开存放。收藏、历史、配置保存在 `%LOCALAPPDATA%\TVBox PC`；替换整个程序目录升级可保留这些数据。与上游 TVBox for Windows 的数据目录独立。豆瓣条目按豆瓣 ID 记忆收藏和观看进度，切源不会生成多份影片记录；旧版本的来源收藏和历史仍可读取。首页提供“继续观看”入口。

单击视频画面显示/隐藏整套播放控制，移动鼠标不会立即重新唤醒手动隐藏的UI；双击仍切换全屏。选集在下一集右侧。常用快捷键：空格暂停/继续，左右方向键快退/快进，F 全屏，Esc 退出全屏或返回，M 静音，`[` / `]` 上一集/下一集。字幕可从播放器菜单加载，本地字幕支持 SRT/ASS/VTT 等格式。

播放器和设置页均可保存选源偏好：速度优先尽快起播并优先低带宽 HLS 变体；高清优先最多等6秒比较首批候选，优先清单分辨率，其次线路/集名明确的画质标签，失败后继续按偏好尝试。未知分辨率不会从站点名称猜测，也不会把清单声明等同于解码器实测。新偏好在下次自动选源生效；播放中点击刷新可后台检测，保留当前流，完成后手动切换。

来源显示实际媒体探测耗时（不含排队，也不是 Ping）：小于1秒绿色、1至3秒橙色、3秒及以上红色；自动显示 ms 或 s。NA 仅表示没有匹配影片，连接/媒体错误显示 ERR。播放 UI 的媒体摘要显示当前解码器分辨率、编码、码率和封装，点击查看详情。未公布的码率保持未知；包数据采样码率会明确标注，暂停时保留上次值，新来源不会继承旧值。流媒体大小若只能按码率推算，会标注“估算”。

弹幕已支持来源自带数据、XML/JSON 数据直链和本地弹幕文件（包括 B 站 XML 格式及 DPlayer JSON）。输入网站主页或影片网页不会自动搜索/匹配弹幕；专门弹幕网站的影片/分集匹配仍需后续服务适配。

需要额外来源时在设置中添加配置。当前保留上游的 JSON、部分 JS 与 Node 兼容能力；Android/JVM JAR、Python Spider 不受支持，不会因“配置加载成功”就视为可播放。

## v0.4.0 影视目录与可选资料

侧栏分类、作品搜索、收藏和历史复用相同筛选控件：年代或年份范围、地区多选、类型多选、指定平台的最低评分及评价人数、热度/年份/评分/人数/名称排序；更多条件包括剧集状态、动画形式和底层影视类型。维度之间同时满足，多选默认满足任一；“类型全部匹配”为可选项。指定条件排除未知字段；未知年份可明确纳入。“清除条件”保留关键词，“全部重置”回到该分类默认条件。

目录请求跨页补全，并显示已检索页数、当前匹配数、缓存和缺失状态。豆瓣目录受接口返回集合限制（最多扫描1000项），TMDB最多500页，不等于任何平台的完整数据库；关键词使用搜索接口，匹配后的筛选与排序持续补全。收藏/历史使用完整本地集合，缺少元数据时不会为筛选强制联网。新目录的条件、列表、分页游标、位置和预设使用独立SQLite保存；首页原推荐瀑布流的列表和位置继续保留，兼容读取0.5.0查询缓存。

当前版本点选海报先进入连续资料与片源详情，详情中的播放按钮才启动播放。详情显示原名、别名、年份、地区、类型、片长、剧情与演职员，评分按豆瓣、TMDB分别显示人数和获取时间，不混合计算。无可靠外部ID时跳转按钮禁用；IMDb评分本版未接入。多季TMDB剧可在详情选季，低置信匹配不会自动绑定，可核对候选或解除TMDB关联。

TMDB个人API Key或Read Token在设置里选填，使用Windows当前用户DPAPI加密保存，不写入普通设置、日志或发布包；需要重新输入才能迁移到另一Windows账号。不填也能使用豆瓣和普通点播；首次主动使用可选资料时提示一次，“不再提示”和已看过状态跨重启保存。设置提供测试连接、删除凭据和资料缓存清理。个人Key请求链路和真实资料已在隔离目录验证；认证协议、缺Key、401和429另有离线覆盖。

播放器“搜索高清源”是接口预留入口，明确提示小雅/G-Box安排在后续版本接入，不会扫描NAS或阻塞当前播放。资料缓存按响应30分钟、详情3天过期，容量超过约128MiB触发清理；保护筛选预设、关联、收藏和历史。清理资料缓存不清除这些记录。


设置顶部“软件更新”检查公开仓库稳定Release。下载按SHA-256核验并暂存，确认安装后正常退出、备份替换并重启，失败回滚；不会强制结束其他窗口。0.8.5及以前的已分发程序没有更新器，需先手动安装0.8.6一次。每个更新包保持纯净，个人资料继续保存在独立目录。弹幕设置可选择B站、内置公共代理、多个自定义聚合服务和自行申请的弹弹play官方AppId/AppSecret；新增服务配置使用当前Windows用户加密保存，不内置私人密钥。

## 从源码构建

需要 Windows x64、Git/Git LFS、.NET 9 SDK、Python 3（安装回滚回归脚本）与 NuGet 网络连接。仓库包含 FFmpeg/Node 的 Git LFS 二进制文件，克隆后确认没有遗留 LFS 指针。

```powershell
./scripts/Build.ps1
./scripts/Build.ps1 -Portable
```

脚本优先使用仓库 `.tools/dotnet` 中的 SDK，否则使用 PATH 上的 dotnet。SDK 可使用微软的 `dotnet-install.ps1 -Channel 9.0 -InstallDir .tools/dotnet` 安装。便携包自带私有运行时，用户无需安装 SDK。

独立执行回归测试：

```powershell
dotnet run --project tests/TVBox.PC.Tests -c Release
python scripts/probe_sources.py
```

回归测试覆盖豆瓣字段、评分缺失、片名/年份/季数、同集续播、32 源并发限制、坏源跳过、取消时的迟到回调、真实 HLS 分片校验，以及原有持久化和字幕行为。实时来源检查写入 `artifacts/source-probe.json`，默认要求至少两个来源通过电影与剧集媒体样本，逐项保留不可用或缺少样本的结果；`--require-all` 可执行更严格的全源样本检查。分片可读仍需通过播放器实测，才算完成播放验收。

测试可设置进程环境变量 `TVBOX_PC_DATA_DIR`，将运行数据隔离到指定的绝对路径；日常使用不需要设置。
